## Anonymization

Names, email addresses, institutional affiliations, personal home-directory
paths, and organization-owned URLs have been replaced with neutral
placeholders (`anonymous`, `/home/user/workspace`). Some links therefore no
longer resolve; this is intentional. Git history was not carried over — the
repository starts from a single commit authored as `Anonymous`.
